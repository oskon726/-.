САПАТТЫ ТЕКШЕРҮҮ ━━━━━━━━━━━━━━━━━━━━ Долбоор даяр болгондон кийин төмөнкү текшерүүлөрдү жүргүз: - Башкы баракча туура ачылат. - Бардык тексттер туура көрүнөт. - Кыргыз тамгалары бузулбайт. - Конверт басылганда сайт ачылат. - Музыка колдонуучунун аракетинен кийин ойнойт. - Календардагы дата туура белгиленет. - Таймер туура эсептейт. - Бардык сүрөттөр көрсөтүлөт. - Галерея иштейт. - Картага өтүү баскычы иштейт. - Телефондо дизайн бузулбайт. - Компьютерде дизайн бузулбайт. - Баракча жаңыртылганда ката чыкпайт. - GitHub Pages шилтемеси туура түзүлгөн. - Браузердин консолунда олуттуу JavaScript каталары жок. Чыныгы GitHub репозиторийине кирүү мүмкүнчүлүгү жок болсо, сайтты интернетке жүктөдүм же текшердим деп жалган айтпа. Анын ордуна мен аткарышым керек болгон кадамдарды так көрсөт. ━━━━━━━━━━━━━━━━━━━━ 16. ЖЫЙЫНТЫКТЫ МАГА ДАЯРДА ━━━━━━━━━━━━━━━━━━━━ Мага жөн гана дизайн же коддун мисалын бербе. Толук иштеген долбоорду даярда. Натыйжада төмөнкүлөр болушу керек: 1. Толук HTML коду. 2. Толук CSS коду. 3. Толук JavaScript коду. 4. GitHub Pages үчүн керектүү конфигурация. 5. README.md нускамасы. 6. Сүрөттөрдү жана музыканы жайгаштыруу боюнча түшүндүрмө. 7. GitHub Pages'ке жайгаштыруунун кадамдары. 8. 404 катасын текшерүү боюнча нускама. Эгер код түзүүчү чөйрө файлдарды түзө алса, бардык файлдарды өзүнчө түзүп, даяр долбоор катары көрсөт. Эгер файлдарды түзө албаса, ар бир файлдын толук кодун өзүнчө бер. Файлдардын аталышын коддун алдында так жаз. Коддун ортосунан бөлүп токтобо. Керектүү функцияларды калтырба. Жок файлдарга иштегендей шилтеме бербе.
